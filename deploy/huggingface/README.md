# Crop Disease Detector — API

FastAPI backend for the Crop Disease Detector website: leaf-photo diagnosis with five ONNX models
(PlantVillage, rice, wheat, soybean, jute pests), disease library, accounts, scan history, admin and the Krishi AI chat.

- Health check: `/api/health`
- API docs: `/docs`
